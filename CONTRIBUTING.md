# Contributing

This is an early preview. Please open a small issue before large changes so the planned desktop and mobile boundaries remain clear.

- Do not include API keys, local data, screenshots of real chats, or private configuration in pull requests.
- Keep tests synthetic. Do not send customer conversations to live services in CI.
- Run npm test before submitting changes.
- Document whether a result is local-only, mock-tested, or verified against a live service.
- Imported SKILL.md files are prompt content. Treat external Skills as untrusted input.
